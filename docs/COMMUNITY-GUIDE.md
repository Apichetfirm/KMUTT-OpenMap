# Contributing without programming

Initiated by Firm Impulse · FIBO FRAB11.

Open the map and search a building or service. Its card shows the available source and uncertainty. Use “แจ้งข้อมูลอาคารผิดพลาด” or the service correction action. The general “เสนอข้อมูล / แจ้งแก้ไข” button also accepts new POIs, hours, closed businesses, geometry corrections and inaccessible paths.

1. Choose the report type and enter a clear title, what changed, when observed and a public source link if available. Coordinates are optional; if included, fill both latitude and longitude. Do not include personal student details, private phone numbers or restricted infrastructure.
2. Press the review button. Read the structured unreviewed proposal before saving/exporting. Changing any field invalidates the previous review.
3. Save locally if you want to return later. Edit/delete and export are available in the form. Local storage is tied to this browser/profile and is not a cloud backup. Export important work.
4. Export JSON or choose “เตรียม GitHub Issue”. The latter prepares an issue; review it and choose to submit on GitHub yourself. Browsing/exporting needs no GitHub account. The map does not submit your report automatically.

For a location/shape proposal, search the building, expand its location-contribution section and select a named source candidate or click/enter a point. Dashed/amber previews and height estimates are unreviewed. Add evidence, preview and confirm. Local coordinates are separate from published coordinates. Export from the directory footer or prepare the stored proposal's GitHub issue. Delete affects only this browser.

If storage is denied, export the reviewed proposal directly. If another tab changed drafts, the app refuses an overwrite: copy/export unsaved work, reload, then retry. Corrupt bytes are preserved and a recovery export is available. Secure-context Web Locks are required for safe local writes. Never clear browser storage before exporting work you need.

Maintainers review source rights, current names, geometry, dates and independent evidence before merging any public change. A community report is not a university confirmation or surveyed route. Staff can follow the institutional process in UNIVERSITY-COLLABORATION.md.
