# คู่มือรับมอบ KMUTT OpenMap

จัดทำ 10 พฤศจิกายน 2569 (Asia/Bangkok) · Initiated by Firm Impulse · FIBO FRAB11

เอกสารนี้เป็นจุดเริ่มต้นสำหรับทีมรับช่วง รุ่นนี้เป็นเว็บแผนที่ชุมชนของนักศึกษา ไม่ใช่บริการอย่างเป็นทางการของมหาวิทยาลัย เปิดใช้ค้นหาและสำรวจข้อมูลโดยประมาณได้ ส่วนความถูกต้องภาคสนามต้องดำเนินงานตามรายการด้านล่าง ผลทดสอบในรายงานเก่าเป็นหลักฐานของ commit เก่า ให้ใช้ผลตรวจที่ลงวันที่และ SHA ตรงกับงานที่จะรับมอบ

## 1. สิ่งที่ได้รับ

- โค้ดเว็บ HTML/CSS/ES modules และ MapLibre ที่เก็บในโครงการ พร้อม license และ lockfile
- รายชื่อ 35 อาคาร: มีจุดอ้างอิงโดยประมาณ 20 อาคาร และไม่มีพิกัด 15 อาคาร
- 73 จุดบริการ OSM ที่ยังไม่ยืนยันภาคสนาม; มีตารางเวลาเพียง 3 รายการและเก่าแล้ว
- 18 ขอบเขตอาคารที่เสนอไว้และทางเดินเสนอ 112 ช่วง ยังไม่ใช่ข้อมูลที่อนุมัติ
- ระบบค้นหาไทย/อังกฤษ รหัส/ชื่อย่อ รายละเอียด แชร์ลิงก์ บริการใกล้เคียง และข้อเสนอแก้ไขในเครื่อง
- เครื่องมือบันทึก/ส่งออกข้อเสนอ หลักฐานภาพ และขั้นตอนทบทวนข้อมูล
- ระบบทดสอบ Node, Python และ Playwright สี่โครงการ: Chromium desktop/mobile, Firefox, WebKit
- `npm run verify` สำหรับตรวจโค้ด ข้อมูล ภาพ unit tests build และ manifest; `npm run handoff` สำหรับจัดชุดส่งต่อ

แหล่งสถานะจริงคือ `data/coverage-report.json` และ [DATA-COVERAGE.md](DATA-COVERAGE.md) อย่านับการเพิ่ม schema หรือทดสอบด้วย fixture เป็นการสำรวจสำเร็จ ภาพถ่ายอาคารที่อนุมัติเผยแพร่ ทางเข้า เส้นทางเดิน และความสูงที่วัดจริงยังเป็นศูนย์

## 2. เริ่มใช้งานในเครื่อง

ต้องมี Node >=20, Python >=3.11 และเว็บเบราว์เซอร์ WebGL2 สำหรับแผนที่สด ตัวเว็บไม่ต้องมีฐานข้อมูลหรือ backend; แผนที่พื้นหลังต้องใช้อินเทอร์เน็ต

จากโฟลเดอร์ repository หรือ `source/` ในชุดส่งมอบ:

```sh
npm ci
npm run verify
node scripts/serve.mjs .site 8080
```

เปิด `http://127.0.0.1:8080/KMUTT-OpenMap/` หากต้องการดู static site ที่ส่งมอบทันที จากโฟลเดอร์ชุดส่งมอบใช้:

```sh
node source/scripts/verify-site.mjs site
node source/scripts/serve.mjs site 8080
```

Windows ใช้ `START_WINDOWS.bat` สำหรับโหมดพัฒนาได้ ห้ามเปิด `index.html` ด้วย `file://` เซิร์ฟเวอร์ท้องถิ่นผูกกับ loopback; การเปิดใช้สาธารณะให้ใช้ static hosting ผ่าน HTTPS และเผยแพร่เฉพาะ `site/` หรือ `.site/`

## 3. ตรวจรับซอฟต์แวร์

```sh
npm run verify
npm audit --audit-level=high
python -m venv work/venv
# Linux/macOS:
work/venv/bin/python -m pip install -r scripts/requirements-images.txt pip-audit==2.10.1
work/venv/bin/python -m unittest discover -s tests -p 'test_*.py'
work/venv/bin/python -m pip_audit --strict -r scripts/requirements-images.txt
npx playwright install --with-deps chromium firefox webkit
CI=1 LIBGL_ALWAYS_SOFTWARE=1 MOZ_WEBRENDER=1 xvfb-run --auto-servernum npm run test:e2e
```

Windows ใช้ `work\venv\Scripts\python.exe` และ `npm run test:e2e` แทน Xvfb บน Linux หากมี system Chromium ให้ใช้ `OPENMAP_CHROMIUM=/usr/bin/chromium npm run test:e2e -- --project=desktop --project=mobile` แต่ผลนี้ไม่ครอบคลุม Firefox/WebKit จำนวนข้อสอบต้องอ่านจากผลรันจริง ห้ามคัดตัวเลขรุ่นเก่ามาใช้

ตรวจบนหน้าจอจริง: เปิดหน้าแรก → ค้น FIBO/N9, หอสมุด/N10, LX/N16 → อ่านชื่อและความไม่แน่นอน → แชร์และเปิดลิงก์ใหม่ → สลับ 2D/3D/กลางคืน → ค้นบริการ → เปิดฟอร์มแก้ไข → ทดสอบเมื่อไม่อนุญาต GPS และโหลดแผนที่ล้มเหลว ตรวจมือถือแนวตั้ง/แนวนอน คีย์บอร์ด และเครดิตแผนที่ ผลจาก emulation ไม่ใช่ผลทดสอบโทรศัพท์จริง

## 4. จัดชุดส่งมอบซ้ำ

ทบทวนและ commit ไฟล์ที่ต้องการส่งก่อน; เครื่องมือคัดลอกเฉพาะไฟล์ที่ติดตามใน Git และรายการโฟลเดอร์ที่กำหนด ห้ามวางหลักฐานส่วนตัวใน `src/`, `data/`, `docs/` หรือ `assets/` เพราะเป็นส่วนที่ตั้งใจส่ง/เผยแพร่

```sh
npm run handoff
```

ผลอยู่ใต้ `work/handoff-<UTC>/` โดยไม่ทับชุดก่อนหน้า และ CI จะเก็บชุดเดียวกันเป็น artifact ชื่อ `kmutt-openmap-handoff-<SHA>` นาน 30 วัน ดาวน์โหลดได้จากหน้า Actions ของ commit นั้น แล้วสำรองในพื้นที่ของทีมก่อนหมดอายุ:

| รายการ | ใช้ทำอะไร |
| --- | --- |
| `source/` | โค้ด เครื่องมือ การทดสอบ เอกสาร และ workflow สำหรับดูแลต่อ |
| `site/` | ไฟล์เว็บที่ build แล้ว พร้อม `release-manifest.json` |
| `survey/` | CSV งานสำรวจอาคาร จุดบริการ และทางเดิน พร้อมช่องผู้รับผิดชอบ/หลักฐาน/ผู้ตรวจ |
| `START-HERE-TH.md`, `OPERATIONS-TH.md` | คู่มือเริ่มต้นและการดูแล |
| `HANDOFF.json`, `DATA-STATUS.json` | วันที่จัดชุด source SHA สถานะ working tree และขอบเขตข้อมูล |
| `SHA256SUMS` | ตรวจความครบถ้วนทุกไฟล์ในชุด ไม่ใช่ลายเซ็นรับรองผู้สร้าง |

บน Linux ตรวจทั้งชุดด้วย `sha256sum -c SHA256SUMS` ก่อนติดตั้ง ต้องดู `source_dirty` ด้วย หากเป็น true ให้บันทึก patch/commit ให้ครบก่อนยอมรับเป็นรุ่นทางการ การจัดชุดไม่รัน browser/audit อัตโนมัติ ต้องเก็บผลคำสั่งข้อ 3 ที่ตรงกับ SHA เพิ่มด้วย

## 5. ข้อมูลที่ต้องทำต่อพร้อมผู้รับผิดชอบที่เสนอ

ชื่อหน่วยงานด้านล่างเป็นบทบาทที่เสนอ ยังไม่มีการติดต่อหรือแต่งตั้งผู้รับผิดชอบแทนผู้ใช้

| ลำดับ | งาน | ผู้รับผิดชอบที่เสนอ | เกณฑ์ตรวจรับ |
| --- | --- | --- | --- |
| P0 | แต่งตั้งเจ้าของบริการ ผู้ดูแลโค้ด เจ้าของข้อมูล และผู้ตรวจข้อมูลอีกคน | เจ้าของโครงการ/หน่วยงานรับช่วง | ชื่อ ช่องทางติดต่อ สิทธิ์ repository/hosting และผู้สำรองครบ |
| P1 | ยืนยัน S1/S2/S6/N19 และขอบเขต N4 | ผู้ดูแลทะเบียนอาคาร/อาคารสถานที่ | เอกสารลงวันที่ระบุรหัส ชื่อ ประวัติ และขอบเขต; ผู้ตรวจอีกคนยอมรับ |
| P1 | สำรวจ N9/N10/N11/N16/N17/N20 แล้วครบ 35 อาคาร | ทีมสำรวจและผู้ตรวจ GIS | ตำแหน่ง หลักฐาน license ทางเข้า และวันสำรวจ ไม่เดาพิกัดจากชื่อ |
| P1 | ยืนยัน 73 บริการและเวลาทำการ | ผู้ประกอบการ/กิจการนักศึกษา | สถานะเปิดปัจจุบัน เวลา วันหยุด และวันที่ยืนยัน |
| P1 | ทดสอบมือถือจริง Android/iOS และการเข้าถึง | QA/ตัวแทนผู้ใช้ | รุ่นเครื่อง/browser/network บันทึกการใช้งาน ปัญหา และผลแก้ไข |
| P2 | ถ่ายภาพนำร่องหกอาคาร | ช่างภาพ/ผู้ดูแลสื่อ | รู้เจ้าของและสิทธิ์เผยแพร่/ดัดแปลง ตรวจอาคารตรงจริง และลบ EXIF ส่วนตัว |
| P2 | ตรวจ 112 ทางเดินและทางเข้าสาธารณะ | อาคารสถานที่/ทีมสำรวจ | ความเชื่อมต่อ ประตู เวลาเปิด พื้นผิว ทางข้าม บันได และผู้ตรวจอิสระ |
| P2 | เส้นทางวีลแชร์ | ทีมการเข้าถึงร่วมกับผู้ใช้จริง | ประเมินความชัน ความกว้าง ผิวทาง ขอบทาง ทุกช่วงและทุกทางเข้า |
| P3 | ความสูง/โมเดลสมจริง | เจ้าของแบบอาคาร/ผู้ตรวจ 3D | แบบหรือการวัดที่อ้างอิงได้ พร้อมสิทธิ์ใช้ข้อมูล |

CSV ในชุดส่งมอบเป็นคิวงาน ไม่ใช่ตัวนำเข้าที่เผยแพร่ทันที เก็บผลสำรวจในพื้นที่ส่วนตัว จากนั้นนำเฉพาะข้อมูลที่ตรวจสิทธิ์และตรวจอิสระแล้วเข้ากระบวนการ PR ตาม [FIELD-SURVEY.md](FIELD-SURVEY.md) และ [DATA-MODEL.md](DATA-MODEL.md) ห้ามเปิด internal routing หรือเลื่อน candidate เป็น verified เพียงเพราะไฟล์ผ่าน validation
