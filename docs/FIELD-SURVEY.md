# Field survey checklist

Initiated by Firm Impulse · FIBO FRAB11.

Start with the generated 35-code review queue and 18 named footprint candidates, including N9/N10/N11/N16/N17/N20. Treat all source points/outlines as approximate until reviewed. Confirm current code/name with university staff; resolve S1/S2/S6/N19 and N4's partial complex before promoting associations.

Survey public areas only with appropriate permission. For each building record licensed outline/source/version, current name, identity rationale, survey/review dates and uncertainty. Record entrances as separate points; never substitute a centroid. Only publish measured heights with credible evidence, or documented floors with their source. Do not infer dormitory demographics, restricted access or sensitive infrastructure.

For paths, use the 112 candidate segments only as a survey work queue. Verify shared intersections on the ground, public access, direction, surfaces/slopes, crossings, stairs/ramps, gate hours/holidays and all building passages. Check linework against actual obstacles, including buildings not yet mapped. Distinct survey and independent reviewers must approve routing records. Accessible routes additionally need an accessibility assessment at every path, junction and entrance.

For services verify current operation, public location, actual entrance if publishing one, operating schedule, exceptions/holiday coverage, observation date and permission/source. A recent source retrieval is not a fresh operator confirmation. Do not publish personally identifying student information.

Export observations as unreviewed proposals with source notes. Independently review geometry/overlaps, rights and access before adding to accepted data; regenerate views and test actual navigation on campus devices before enabling it. See UNIVERSITY-COLLABORATION.md for suggested owners and acceptance.
